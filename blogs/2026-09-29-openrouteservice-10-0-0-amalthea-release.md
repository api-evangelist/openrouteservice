We are announcing the major release of openrouteservice with version 10.0.0 also known as Amalthea. This release focuses mostly on our technical foundation. It upgrades Java and Spring Boot, reduces the set of release artifacts to a fat jar and Docker images, and moves the slim Docker image to a hardened distroless base.
